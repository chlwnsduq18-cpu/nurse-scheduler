# 간호사 스케줄러 — 직군별 편성 개정판

전체 배포 폴더에 HTML·CSS·JS, nurse_scheduler_template.xlsx, vendor 라이브러리가 포함되어 있습니다. GitHub Pages 또는 로컬 HTTP 서버에서 index.html로 접속하세요. 엑셀 출력은 로컬 라이브러리를 사용하며 외부 CDN이 필요하지 않습니다. 실행 방법은 [엑셀 출력 안내](EXCEL_TEMPLATE_SETUP.md)를 참고하세요.

## 사용 순서

1. 간호사 정보에서 HN/RN/MD/NK/AN 분류를 확인합니다.
2. 날짜별 모달에서 D/E/N/M/O 또는 **휴가 · O**를 입력합니다.
3. **편성 규칙**에서 실제 근무·휴게시간, 직군별 주말 근무 가능 여부, 날짜 유형별 필요 인원을 확인합니다.
4. 자동 생성 후 붉은 날짜와 상단의 사유 목록을 확인합니다.
5. 수동 수정 후 재생성하거나 엑셀로 출력합니다. 엑셀의 `편성 확인` 시트에는 부족·초과 사유가 표시됩니다.

## 기본 규칙

| 구분 | 평일 | 일반 토요일 | 일요일·공휴일 |
|---|---|---|---|
| D 간호사 | HN+RN 최소 2명 | RN 최소 2명 | RN 최소 1명 |
| E 간호사 | RN 최소 2명 | RN 최소 1명 | RN 최소 1명 |
| N 간호사 | NK 1명+RN 1명 | NK 1명 | NK 1명+RN 1명 |
| AN | D/E 각 최소 1명 | D/E/N 각 1명 + M 최소 1명 | D/E/N 각 1명. 토·일요일이면 M 최소 1명 추가 |
| M | MD 우선, 공백 시 RN. 합계 최소 1명 | AN 최소 1명 | 일요일·주말 공휴일은 AN 최소 1명. 평일 공휴일은 M 필수 배정 없음 |

AN은 D/E/N 간호사 필요 인원을 대신하지 않습니다. M은 주말에 AN이 담당합니다. 화면 상단 D/E/N/M 합계는 전체 직원을 합산하지만, 부족 여부는 직군별로 검사합니다.

공휴일인 토요일에는 **공휴일 규칙**이 우선합니다. N은 설정 정원을 초과하여 자동 배정하지 않습니다. N 총원을 1명보다 크게 설정하면 NK 1명 외의 자리는 RN으로 구성합니다. NK가 부족해도 다른 직군을 NK로 간주하지 않고 부족을 표시합니다.

- **HN**: D만. 기본 주말 OFF, 공휴일 OFF.
- **RN**: D/E/N. N을 2~3일 묶음으로 배정하고 묶음 종료 후 다음 근무까지 최소 2일 OFF. 평일(공휴일 제외)에 MD가 비면 M 대체. 주말 M은 자동 배정하지 않음.
- **MD**: M만. 주말·공휴일 OFF 고정. 이전에 주말 가능으로 저장한 설정도 불가로 정리하며 직접 지정한 배정은 변경하지 않음.
- **NK**: N만. 두 명이 2~3일 근무와 2~3일 OFF를 교대로 하며 월 절반씩 분담. 28/29/30/31일인 달에 각각 14·14 / 14·15 / 15·15 / 15·16일을 목표로 함. 원티드·인원·이웃 달 조건에 의해 충족하지 못하면 경고.
- **AN**: 별도 인원, 주 최대 5일. 토·일요일 M 필수 담당, 평일 M은 자동 배정하지 않음. 주말·공휴일 N 종료 후 최소 2일 OFF. 평일 N 필요 인원이 0인 기본 설정에서는 평일 N을 자동 배정하지 않음.

기존 주 최대 5일, 최대 연속 5일 기본값, 설정상 실근로 1일 8시간/주 40시간, 근무 사이 11시간 보수적 휴식 기준을 유지합니다. 추가 최대 연속 근무 규칙은 조정 가능하며 직군별 N 최대 3일 제한은 유지합니다. N 후 휴식 규칙은 기본보다 길게 설정할 수 있습니다.

## OFF와 휴가

- 미배정 또는 자동 OFF: 화면에 O. 재생성에서 근무로 바뀔 수 있음.
- 직접 지정 O: 사용자 지정으로 보호.
- 휴가: 데이터상 O이지만 `leave`에 휴가 표시를 따로 저장. **분홍색 ‘휴가’**로 표시하고 엑셀에도 휴가로 출력.
- 휴가나 지정 O를 다른 근무로 바꾸거나 지정 해제하면 휴가 표시도 제거.
- 평일(공휴일 제외) M은 MD/RN 합계 최소 1명. MD 휴가뿐 아니라 일반 지정 O, MD 미등록, 근무 한도 등으로 MD 배정이 비면 RN이 대체. MD가 배정되어 있으면 RN을 중복 대체하지 않음.
- 토·일요일에는 공휴일 여부와 무관하게 AN M 최소 1명. 평일 공휴일에는 기존 공휴일 OFF 기준을 유지하여 M을 필수로 요구하지 않음. 수동 지정이 이 조건과 달라도 변경하지 않고 경고함.
- 휴가 잔여일·차감은 계산하지 않음. 기존 O를 임의로 휴가로 바꾸지 않음.

NK 이외 직군은 기본 OFF 및 원티드 OFF를 확보한 뒤 주간 근무 목표까지 추가 배정합니다. HN/MD의 근무 불가 휴일에는 억지로 주 5일을 채우지 않습니다. 원티드 O는 이전 합의대로 기본 OFF에 추가하며, 원티드가 없는 일반 주는 5일, 원티드 O가 1일이면 4일을 목표로 합니다. NK에는 주 5일 채우기 대신 월 절반 분담 목표를 적용합니다.

## 데이터와 재생성

- `assignments`: 현재 근무표.
- `wanted`: 사용자 확정 D/E/N/M/O.
- `leave`: 사용자 휴가 표시. 근무 코드를 늘리지 않고 O와 결합.
- `rosterSettings`: 직군별 주말 가능 여부와 날짜 유형별 필요 인원.
- `holidayYears`: 연도별 공휴일 목록과 확인 여부.
- `generationSnapshot`: **최신 자동 생성 스냅샷 한 개만** 유지.

기존 localStorage 키를 유지합니다. 출처 정보가 없는 아주 오래된 배정은 사용자 지정으로 보존합니다. 파일을 다른 경로에서 열어 이전 데이터가 보이지 않으면 브라우저의 파일별 저장 영역이 다를 수 있습니다.

생성은 원티드를 고정하고, NK 교대와 RN/AN N 묶음을 만든 뒤 주간 배정과 개인별 근무 목표를 채웁니다. 여러 후보에서 필요 인원 부족, NK 분담 부족, 개인 근무 목표 부족을 줄이고 그다음 기존 스냅샷과의 변경을 줄입니다. 저장 실패 시 기존 근무표와 스냅샷을 유지합니다.

탐색은 제한된 횟수의 휴리스틱입니다. 붉은 표시는 현재 탐색에서 충족하지 못한 결과 또는 사용자 지정 위반이며, 수학적으로 편성이 불가능하다는 증명은 아닙니다. 사용자 입력이 규칙을 위반해도 자동 수정하지 않습니다.

앞뒤 월에 저장된 배정은 주간 한도와 휴식 검사에 포함합니다. 미입력 이웃 날짜는 OFF로 취급하므로 다음 월을 편성할 때 다시 확인해야 합니다. 현재 월 밖에 자동 배정을 임의로 쓰지 않습니다.

## 병원 템플릿 엑셀 출력

현재 월 초기화는 두 가지입니다. **원티드 유지 초기화**는 직접 지정한 근무·OFF·휴가를 남기고 자동 배정과 해당 월의 자동생성 스냅샷을 지웁니다. **월 전체 초기화**는 해당 월의 원티드·휴가까지 모두 지웁니다. 다른 월, 직원 정보, 편성 규칙은 유지합니다.

`index.html` 옆에 `nurse_scheduler_template.xlsx`를 놓으면 원본 서식을 이용해 근무표를 다운로드합니다. 적용 파일, 직원 배치, 집계 기준과 인쇄 설정은 [엑셀 출력 안내](EXCEL_TEMPLATE_SETUP.md)를 참고하세요. 템플릿의 직책은 셀 내용만 비우고 열 위치와 이중선은 유지합니다.

## 검증 범위

자동 검증으로 직군별 분리 인원, 토요일/공휴일 우선순위, N 묶음, 주간 근무·휴식 한도, 28~31일 NK 분담 패턴, 원티드 보호, 휴가 변경·해제, MD 대체, 재생성 유지, 미지원 연도 확인, 저장 실패 시 원상 유지, 직원 삭제 시 관련 데이터 정리를 점검했습니다.

M 개정판은 평일 MD 우선, 휴가·일반 O·MD 미등록 시 RN 대체, 주말 AN M 필수 배정, 주말 MD/RN M 및 평일 AN M 자동 배정 제외를 추가 검증합니다. 인원 부족이나 근무 목표 미충족은 경고로 남습니다. 실제 브라우저 화면을 실행한 시각 검증은 수행하지 못했습니다.
