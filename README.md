
http://localhost:8080/index.html 에 접속합니다. 엑셀 출력은 함께 들어 있는 `nurse_scheduler_template.xlsx`와 로컬 vendor 라이브러리를 사용하며 CDN에 의존하지 않습니다. 사용자가 수정한 병원 템플릿은 보관해서 그대로 사용하세요.

## 새 기본 배치 기준

| 근무 | 일반 월~금 | 토·일 및 평일 공휴일 | 집계 대상 |
|---|---:|---:|---|
| D | RN 2명 | RN 1명 | RN 고정 인원; HN을 대신 세지 않음 |
| E | RN 2명 | RN 1명 | RN 고정 인원 |
| N | 2명 | 1명 | RN+NK 합계 최소 필요 인원 |

HN은 D만, 주말·공휴일 OFF입니다. HN의 평일 D는 RN D 인원과 별도입니다. MD는 평일 M 전담이고 주말·공휴일 OFF입니다. 평일 M 공석은 RN이 대체하며 주말 M은 AN이 담당합니다. 평일 공휴일 M은 기본 필수 인원이 없습니다.

**N 1명은 RN 또는 NK 한 명이 필요하다는 뜻입니다.** 기존 NK 겹침 허용을 유지하므로 개인별 월 N 목표를 채울 때 최소 필요 인원을 넘길 수 있습니다. N을 엄격히 1명으로 제한하려면 간호사/주말·공휴일/N 최대 1명 규칙을 추가하세요. 이 경우 개인별 목표와 충돌할 수 있으며 미충족을 표시합니다.

AN은 간호사 인원을 대신하지 않고 기존 별도 규칙을 유지합니다. 일반 평일 D/E 각 1명, 토·일·공휴일 D/E/N 각 1명, 토·일 M 최소 1명입니다. 화면 상단 카운트는 전체 직원 합계이며 부족·초과 검사는 직군별로 분리합니다.

## 추가 규칙과 자동생성

`편성 규칙`의 추가 규칙에서 RN 월 N 최소/최대(기본 4~5), NK 개인별 월 N 횟수(기본 15), RN/NK N 묶음 최소/최대(기본 2~3), N 종료 후 최소 OFF(기본 2), 근무 사이 최소 휴식(기본 11시간), NK N 묶음 길이만큼 OFF 선호(기본 1)를 조정합니다. NK는 달 길이와 관계없이 각 15회입니다.

기존 최소·최대 인원, 최대 연속 근무일, 주간 최소 OFF, 선호 근무도 생성과 검사에서 사용합니다. 인원 규칙은 대상(간호사/AN/각각)과 날짜(일반 평일/주말·공휴일/전체)를 지정합니다. 같은 종류·근무·대상·날짜의 중복 규칙은 위 항목이 우선입니다. 서로 겹치는 최소 규칙은 큰 값, 최대 규칙은 작은 값을 적용합니다. 삭제한 개인별 규칙은 기본값으로 돌아갑니다.

D/E 자동 배정은 설정된 RN 고정 인원을 넘기지 않습니다. 추가 최소 인원으로 기준을 높일 수 있고, 추가 최대 인원이 그보다 작으면 충돌 사유를 표시합니다. N 최대 규칙은 NK 독립 재탐색을 포함한 모든 자동 배정 경로에 적용합니다. 선호 근무는 가능한 후보의 점수에 반영하며 다른 필수 조건을 완화하지 않습니다. 기본 담당 직군·요일과 충돌하는 M 최소 규칙도 조용히 무시하지 않고 부족으로 표시합니다.

N 묶음 바로 앞뒤에 D/E/M을 붙이지 않습니다. N 종료 후 설정된 OFF와 주간 최대 5일, 최대 연속 근무, 시간 설정에 따른 주간 상한을 검사하며 이웃 월의 저장된 배정도 포함합니다. NK의 N2→OFF2/N3→OFF3은 선호 기준입니다. OFF 선호를 0으로 꺼도 필수 최소 휴식은 유지합니다.

## 월 휴무 기준

이번 달 **토요일·일요일·공휴일 날짜 수**를 자동 합산하며 겹친 날짜는 한 번만 셉니다. 과거 고정 9일 기본값은 사용하지 않습니다. 공휴일을 수정하면 자동 기준도 바뀝니다. `이번 달 OFF 기준을 직접 지정`을 체크한 경우에만 해당 월의 수기 값을 적용합니다.

원티드·일반 지정 OFF도 휴무에 포함하며 휴가는 별도로 처리합니다. NK는 월 OFF 목표 대신 개인별 N 횟수를 적용합니다. HN/MD의 근무 불가일을 억지로 근무로 채우지 않습니다. 이 숫자는 편성용 월 휴무 기준이며 O가 법률상 유급 주휴 지정이라는 뜻은 아닙니다.

고정 D/E 인원, RN/NK 월 N, OFF 목표, N 전후 휴식은 직원 수나 원티드에 따라 동시에 충족되지 않을 수 있습니다. 자동생성은 사용자 지정을 변경하거나 상한을 무시해 채우지 않으며 날짜별 부족/초과, 개인별 월 N 미충족, 월 OFF 초과, 최소/최대 충돌을 표시합니다. 제한된 후보 탐색 결과의 미충족은 수학적으로 편성이 불가능하다는 증명은 아닙니다.

## 사용자 지정·저장·재생성

- `wanted`: 체크된 원티드. `manual`: 체크를 끈 일반 수동 조정. 두 종류 모두 자동생성이 보존합니다.
- 날짜 입력창/근무 형태 변경창에서 원티드 체크 후 D/E/N/M/O/휴가 버튼을 누르면 즉시 저장합니다.
- 미배정은 O로 표시하지만 다시 배정할 수 있습니다. 직접 O와 휴가는 보호합니다.
- 원티드 유지 초기화는 해당 월의 일반 수동 조정과 자동 배정을 지우고 원티드만 남깁니다. 월 전체 초기화는 해당 월의 원티드/휴가까지 지웁니다.
- 최신 자동생성 스냅샷 하나만 유지합니다. 다른 월과 이번 달 편성에서 제외한 직원의 기록은 보존합니다.
- 직원 순서 드래그/Alt+방향키, 월별 편성 인원, 엑셀의 간호사/AN 구역 분리를 유지합니다.
- 기존 localStorage 키를 유지합니다. v14에서 새 기본 인원과 HN 주말 OFF를 한 번 적용하고 새 추가 규칙을 보완합니다. 저장된 근무표·원티드·일반 조정·휴가를 삭제하지 않습니다. 기존 AN 인원과 이미 지정한 추가 규칙값은 보존합니다.

## 파일 역할

| 파일 | 역할 |
|---|---|
| `index.html`, `nurse-scheduler.css` | 화면과 스타일 |
| `nurse-scheduler.js` | 입력, 규칙 저장, 표시, 결과 적용 |
| `nurse-scheduler-model.js` | 화면/Worker 공통 날짜·직원·사용자 지정 조회 |
| `nurse-scheduler-rules.js` | 규칙 정의·검증·저장 데이터 이전 |
| `nurse-scheduler-engine.js` | 공통 배정 조건, 자동생성, 결과 분석 |
| `nurse-scheduler-worker.js` | 화면과 분리된 자동생성 계산 |
| `nurse-scheduler-excel.js`, template, vendor | 병원 양식 엑셀 출력 |

HTTP/GitHub Pages에서는 Worker에서 탐색하므로 계산 도중 화면을 사용할 수 있습니다. 도중에 월이나 입력이 바뀌면 결과를 폐기하고 현재 입력을 보존합니다. Worker 파일 로딩 오류와 저장 실패 때 기존 근무표를 유지합니다. Worker를 지원하지 않거나 HTML을 파일로 직접 열면 기존 동기 계산을 사용합니다.
