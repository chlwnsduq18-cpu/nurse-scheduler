자동 편성 규칙

자동 스케줄 생성에 적용할 기본적인 편성 논리를 설정합니다.

기초 편성 기준 및 근무시간

주 최대 5일 · 근무 사이 11시간 휴식 · 원티드/휴가는 변경하지 않습니다. 기본 RN 월 N 4~5회, NK 1인 월 N 15회입니다. N 2~3일 묶음과 종료 후 OFF 2일 이상을 적용합니다. 횟수·묶음·휴식은 아래 추가 규칙에서 조정합니다. AN의 주말·공휴일 N 뒤 OFF 2일 이상. HN/MD의 기본 공휴일 OFF는 개인 휴가로 계산하지 않습니다.

D 07–15 / E 15–23 / N 23–07, 각 휴게 30분은 예시입니다. M 09–18은 휴게 60분으로 시작합니다. 근로시간은 근무 시작일 기준으로 합산합니다. O 표시는 유급 주휴 지정이 아니며, 휴게의 실제 보장·야간근로 동의·휴일 및 특례 적용까지 판정하지 않습니다.

근로기준법 제50조 · 제54조 · 제55조

직군·요일별 추가 편성 규칙
이번 달 기준 OFF:

기본값은 이번 달 토·일·공휴일 날짜 수이며 겹치는 날짜는 한 번만 셉니다. 직접 지정은 해당 월에만 적용합니다. 원티드·수동 OFF도 포함하고 휴가는 별도로 계산합니다. NK에는 개인별 월 N 횟수 기준을 적용합니다. N 묶음 앞뒤에는 다른 근무를 바로 배정하지 않습니다.

HN은 D만, 주말·공휴일 OFF(고정). MD는 M만, 주말·공휴일 OFF(고정). RN은 주말 M 불가, AN은 주말 M 담당입니다. 토·일·평일 공휴일의 간호사 D/E/N 기본 인원은 각각 1명입니다.

D/E는 RN 고정 인원(기본 일반 평일 각 2명, 주말·공휴일 각 1명)입니다. HN의 D는 별도이며 RN 필요 인원을 대신하지 않습니다. N은 RN+NK 합계 최소 인원(평일 2명, 주말·공휴일 1명)입니다. 기존 NK 겹침 허용을 유지하므로 개인별 월 횟수를 채울 때 N 필요 인원을 넘길 수 있습니다. 엄격한 N 정원이 필요하면 추가 최대 인원 규칙을 설정하세요. AN은 별도 인원이며 기존 D/E/N 및 주말 M 규칙을 유지합니다. M은 일반 평일 MD 우선·공석 시 RN 대체, 토·일 AN 담당이고 평일 공휴일에는 기본 필수 인원이 없습니다. 고정 인원과 월 OFF 목표가 충돌하면 초과 배정으로 숨기지 않고 미충족을 표시합니다.

공휴일 관리

2026년 공휴일 기본 목록을 제공합니다(2026-09-14 확인). 임시공휴일 변경은 직접 추가하세요. 다른 연도는 목록 입력·확인 후 생성할 수 있습니다. 일요일은 따로 입력하지 않아도 됩니다.

2026년 월력요항 · 제헌절 공휴일 지정

같은 대상·날짜·종류의 중복은 위 규칙 우선. 새 개인별 기준도 여기서 관리합니다.

인원 규칙은 간호사/AN과 일반 평일/주말·공휴일 대상을 선택합니다. 최소 규칙은 위 필요 인원을 높이고 최대 규칙은 배정 상한을 제한합니다. 삭제한 개인별 규칙은 기본값(RN N 4~5, NK N 15, N 묶음 2~3, N 후 OFF 2, 근무 사이 11시간)으로 돌아갑니다. NK 묶음 길이만큼 OFF는 1=선호 적용, 0=선호 해제입니다. 선호는 필수 규칙을 완화하지 않습니다. 원티드·일반 수동 조정은 자동 수정하지 않으며 충돌 이유를 표시합니다.

근무 형태 변경

배정된 간호사의 근무를 변경합니다.

체크 여부를 정한 뒤 근무 버튼을 누르면 바로 저장됩니다. 두 종류 모두 자동 생성이 보호합니다.

M은 평일 MD 우선·공백 시 RN 대체, 주말 AN 담당입니다. MD/RN은 주말 M, AN은 평일 M에 자동 배정하지 않습니다. 휴가는 분홍색으로 표시합니다.
O를 선택하면 지정 OFF로 보호합니다. 미배정도 O로 표시되지만 자동 배정이 가능합니다.
🔒 사용자 지정은 자동 생성 시 유지됩니다. 지정 해제로 보호를 해제할 수 있습니다.
